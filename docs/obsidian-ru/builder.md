# builder - это
основной класс для построения [[ui_scheme|чертежа пользовательского интерфейса]] интерфейса. Он основан на одноименном паттерне проектирования.
## Причины
Данный подход был использован для удобства создания.[[builder|Builder]] инкапсулирует всю сложную логику создания и преобразование [[element]] через [[context]].

# Интерфейсы строителя
Используются для создания и настройки элементов.
- [[builder/uid]]
- [[builder/element]]
- [[policy]]
- [[event]]
- [[state]]
- [[builder/style]]
