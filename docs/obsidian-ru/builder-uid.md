# uid
Используется для создания [[uid|уникального идентификатора]] и ветвления элементов.
## Примеры
```c++
ctx.make([](context::builder &b){
  b.element.frame([](context::builder &b){
      auto uid = b.uid.make(policy::unique{},                                     "my-element");
      b.uid.branch(uid);
  });
});
```
# Ветвление
Дочерний элемент автоматически наследует родительский uid. Чтобы предать элементу уникальности используется функций **branch**.
```c++
b.uid.branch(uid);
```
>[!Why]
> Многим элементам не требуется уникальность, поэтому была сделана система с автоматическим наследованием uid родителя.
# Политики создания uid
### unique
>[!Info] Unique
>```c++
>b.uid.make(policy::unique{},"my-element");
>```
> Создает уникальный uid для текущего элемента.
### shared
>[!Info ] Shared
>```c++
>b.uid.make(policy::shared{},"my-element");
>```
> Создает идентичный для каждого братского элемента uid.
### indexed
>[!Info] Indexed
>```c++
>b.uid.make(policy::indexed{},"my-element");
>```
> Создает индексированный относительно родителя uid. Каждый вызов этой функции увеличивает индекс родительского элемента на 1.
