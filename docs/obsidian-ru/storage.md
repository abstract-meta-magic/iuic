# storage - это
Точка доступа к данным [[context|контекста]].
## ключ
Используются для доступа к хранящемся в хранилище данным.
### ork_t(object_registry_key)
Используется хранилищем [[storage#хранилища#object_storage|объектов]].
### trk_t(text_registry_key) 
Используется хранилищем [[storage#хранилища#text_storage|текстовых буферов]].
