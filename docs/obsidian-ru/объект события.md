## Локальные
Срабатывают только если элемент имеет статус **hovered**.
```c++
b.event([](event::local::*) { ... });
```
## Глобальные
Срабатывают *независимо* от статуса **hovered**.
```c++
b.event([](event::global::*) { ... });
```
