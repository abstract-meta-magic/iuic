# uid
Используется для создания [[uid|уникального идентификатора]] и ветвления элементов.
## Примеры
```c++
ctx.make([](context::builder &b){
  auto uid = b.uid.make(policy::unique{},                                     "my-element");
  
  b.element.frame(uid,[](context::builder &b){
    // содержимое
	auto inner_uid = b.uid.make(policy::shared{1},
	                            "shared-state");
								
	auto ork = b.storage.object.persist(uid,
	                           "shared-object");
  });
});
```
# Ветвление
Дочерний элемент автоматически наследует родительский *uid*. Чтобы предать элементу уникальности, *uid* передается явно.
```c++

// родительский uid
b.element.frame([](context::builder &b){ ... });

uid_t uid = ...;
// сгенерированный uid
b.element.frame(uid,[](context::builder &b){ ... });
```
>[!Why]
> Многим элементам не требуется уникальность, поэтому была сделана система с автоматическим наследованием *uid* родителя.
# Политики создания uid
### unique
>[!Info] Unique
>```c++
>b.uid.make(policy::unique{},"my-element");
>```
> Создает *uid* на основе положения в *иерархии* текущего элемента и *uid* последнего дочернего элемента. Изменение порядка  элементов , влияют на генерацию этого *uid*.
### shared
>[!Info ] Shared
>```c++
>// по умолчанию 0
>b.uid.make(policy::shared{},"my-element");
>// но можно явно задать число
>b.uid.make(policy::shared{2},"my-element"});
>```
> Создает *uid* на основе положения в *иерархий* относительно заданного элемента. Число указывает на сколько нужно подняться вверх по иерархии. Изменения *uid* и расположения текущего элемента, влияют на генерацию этого *uid*.
### indexed
>[!Info] Indexed
>```c++
>b.uid.make(policy::indexed{},"my-element");
>```
> Создает *uid* согласно *индексу* текущего элемента. Каждый вызов этой функции увеличивает *индекс* текущего элемента на *1*. Изменение положения в *иерархии* текущего элемента, влияет на генерацию этого *uid*.


# Таблица применений
## Нужны правки

| Политика  | Когда использовать                                        |
| --------- | --------------------------------------------------------- |
| `unique`  | Уникальные элементы                                       |
| `shared`  | Общее состояние                                           |
| `indexed` | Перечисляемые <br>элементы, <br>индексированное состояние |
